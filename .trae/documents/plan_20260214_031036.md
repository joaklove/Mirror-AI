# Mirror AI 道系国风设计方案

## 设计目标
- 融入道系元素和中国传统美学
- 保持应用功能完整性
- 创建独特的国风视觉体验
- 与现有明亮主题基础相结合

## 核心设计元素

### 1. 颜色系统

**主色调：**
- **玄天色**：#1a1a2e（深蓝黑色，象征宇宙）
- **青竹色**：#4a7c59（青绿，象征自然）
- **朱砂红**：#c14953（暗红，象征活力）
- **玉白色**：#f8f4e3（米白，象征纯净）

**辅助色：**
- **松花色**：#c9d8b6（淡黄绿，象征生机）
- **藕荷色**：#d6a4a4（淡粉红，象征温柔）
- **石青色**：#3a506b（灰蓝，象征稳重）

### 2. 字体与排版

**字体选择：**
- 标题：使用具有书法风格的字体
- 正文：使用清晰易读的思源宋体或相似字体

**排版特点：**
- 适当增加行间距，体现疏朗之美
- 标题使用竖排或斜体效果增强国风感
- 重要内容使用印章风格强调

### 3. 图标与装饰

**核心图标替换：**
- 太极图标替代现有 Sparkles 图标
- 云纹、如意、灵芝等传统图案作为装饰
- 八卦元素用于功能分区标识

**装饰元素：**
- 页面边框添加云纹装饰
- 卡片边角使用如意纹造型
- 按钮添加传统花纹背景
- 分割线使用水墨风格

### 4. 布局与结构

**布局调整：**
- 顶部导航添加中式屋檐造型
- 主内容区采用卷轴式布局
- 侧边添加竹简风格的标签栏
- 底部添加中式花纹装饰

**空间感：**
- 增加留白，体现道家「空」的哲学
- 层次分明，模拟传统建筑的檐角层次
- 对称布局，体现中式美学平衡感

### 5. 交互与动画

**动画效果：**
- 页面切换使用卷轴展开效果
- 按钮点击使用水墨扩散效果
- 加载状态使用太极旋转动画
- 数据变化使用毛笔书写效果

**交互反馈：**
- 悬停效果使用水墨晕染
- 点击效果使用印章盖章
- 错误提示使用宣纸褶皱效果

### 6. 功能区域设计

**日记输入区：**
- 采用宣纸背景
- 输入框设计为毛笔书写效果
- 标签改为印章样式

**晨报生成区：**
- 报告以卷轴形式展示
- 内容排版模仿古籍样式
- 添加传统节气、天干地支信息

**设置区域：**
- 采用竹简风格的选项卡
- 背景使用古籍纸张效果
- 按钮设计为木质令牌样式

## 技术实现方案

### 1. CSS 变量更新
- 修改 `src/index.css` 中的颜色变量
- 添加道系风格的字体导入
- 定义装饰性 CSS 类

### 2. 组件样式调整
- 更新 `src/pages/Index.tsx` 中的组件样式
- 替换图标为道系风格图标
- 调整布局结构和装饰元素

### 3. 新资源添加
- 导入国风字体文件
- 添加云纹、太极等 SVG 图标
- 创建道系风格的背景图案

### 4. 功能增强
- 添加节气、天干地支显示
- 实现卷轴式页面切换动画
- 集成水墨风格的交互效果

## 预期效果

通过以上设计，Mirror AI 将转变为一个具有浓厚道系国风特色的应用，同时保持其核心功能完整性。用户将获得独特的视觉体验，感受到中国传统文化的魅力，同时享受到现代化的 AI 辅助功能。
